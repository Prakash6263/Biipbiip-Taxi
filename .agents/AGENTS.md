# User Preferences & Constraints

## Browser Execution Rule
- **NEVER** run, preview, or test code in a web browser or local browser automatically.
- Do not use the browser subagent or any browser-related tools (like `browser_subagent`) to load, run, or verify code or web applications on the local machine or any web page unless the user explicitly requests you to do so.
- When the user provides code, do not launch or interact with any browser automatically.
